## The Caeser Cipher implemented in many languages

A script to encrypt/decrypt Caeser Cipher messages in every programming language I know

## Specifications

The code should:
- Include the `encrypt(plaintext, key) -> ciphertext` function
- Include the `decrypt(ciphertext, key) -> plaintext` function
- Ask the user for a plaintest message and a numerical key (Integer from 1 to 25)
- Support UTF-8 characters (support for other characters is not required)
- Output non-alph characters directly without performing any encryption/decryption

## Purpose

**All of these files were written by me, with no AI assistance.**

My point with this repo is to try and learn new stuff, not the end result of having the ceaser cipher in all these languages (that is a bit pointless).

As such I will also reject any PRs (if any ever happen) that add new languages, as I won't have learned from them.
